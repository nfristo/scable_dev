# Scable Dev

**Project information:** ADEME Graine.

Le dossier Scable Dev contient 3 sous-dossiers : script, resources et results. 

Le sous-dossier script contient : 

 - cable_analysis : tous les scripts permettant les analyses des données câble, numérotés de 1 à 8 et d'un titre. 
                    Chaque script contient la description de ce qu'il permet de faire.
 
 - land_analysis : tous les scripts permettant les analyses des données terrestres, numérotés de 1 à 6 et d'un titre.
                   Chaque script contient la description de ce qu'il permet de faire.
                   
 - cable_data_management : contient 2 scripts qui ont permis de ranger proprement les données de la base câble, qui comporte des erreurs de saisies

Le sous-dossier resources contient :  

 - inhouse : toutes les bases de données de l'ONF
 
 - public : les données publiques utilisées dans les script (IGN)
 
Le sous-dossier results contient :  

 - global : tous les csv créés et utilisés dans les scripts 
 
 - plots : une partie des graphiques créés 
 
 - data_management : les csv créés après le traitement des données ONF dans les scripts de cable_data-management
